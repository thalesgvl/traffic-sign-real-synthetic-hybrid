# Configurations

- [`train/`](train/): the `args.yaml` written by Ultralytics for each of the three
  training runs (real, synthetic, hybrid), unchanged except for local absolute paths,
  which are replaced by paths relative to the repository root.
- [`data/`](data/): the `data.yaml` files of every training regime and benchmark,
  with the class order used by the models.

*Pending:* files will be added from the training machine.
